# 우사기의 용산 오픈런 · v4

본 게임은 비공식 팬게임이며, 원작자(Nagano) 및 치이카와 공식 제작사와 관련이 없습니다

PC 키보드와 모바일 터치로 즐기는 픽셀 액션 팬게임입니다.
**치이카와 되팔렘 하지마라! 굿즈좀 사자ㅡㅡ**

## GitHub Pages에 올리기

빌드나 설치 없이 `index.html` 한 파일로 실행됩니다. 이미지, 음악, 코드가 모두 포함되어 있습니다.

1. 이 ZIP 파일의 압축을 풉니다.
2. https://github.com/new 에서 저장소를 만듭니다. 이름 예: `usagi-openrun`. 무료 계정은 **Public**으로 선택합니다.
3. 저장소의 **Add file → Upload files**를 누릅니다. 빈 저장소라면 **uploading an existing file** 링크를 사용할 수 있습니다.
4. 압축을 푼 **index.html**을 저장소 최상위에 업로드하고 **Commit changes**로 저장합니다. ZIP 자체나 상위 폴더를 올리지 마세요. README.md와 .nojekyll도 함께 올릴 수 있습니다.
5. **Settings → Pages → Build and deployment → Source: Deploy from a branch**를 선택합니다.
6. **Branch: main**, **Folder: /(root)**를 선택하고 **Save**를 누릅니다. 기본 브랜치 이름이 다르면 실제 파일을 올린 브랜치를 선택하세요.
7. 배포가 완료되면 Pages 화면의 **Visit site**를 누릅니다. 일반적인 주소는 `https://사용자이름.github.io/usagi-openrun/`입니다.

이미 저장소가 있다면 기존 index.html을 이 파일로 교체하고 커밋하면 됩니다. 업로드 전 로컬에서 index.html을 브라우저로 열어 실행할 수도 있습니다. 수집 기록은 최종 GitHub Pages 주소에서 플레이하는 것을 기준으로 저장하세요.

## 이번 버전

| 구역 | 배경 | 적 |
| --- | --- | --- |
| 1 | 기존 용산 밤샘 대기 공간 유지 | 캐리어를 끄는 롱패딩 되팔렘 6명 |
| 2 | 해 뜨는 용산역 앞 광장 | 파마머리·안경·장바구니 차림의 아줌마 되팔렘 10명 |
| 3 | 분홍 매장 쇼윈도와 입구 대기줄 | 굿즈 쇼핑백과 피규어 상자를 들고 다시 줄 선 되팔렘 14명 + 모몽가 |

- 난이도는 MEDIUM+. 구역을 지날 때 체력 2칸 회복, 실패하면 해당 구역부터 재도전합니다.
- 보스는 맞을 때마다 괴물 얼굴이 잠깐 드러납니다. 푸른 소환 예고 후 귀여운 작은 모몽가 2~3마리를 부릅니다.
- 소환된 모몽가는 주먹·불구름으로 제거하거나 대시로 회피할 수 있습니다. 코인은 주지 않습니다.
- 토벌봉은 보스 등장 시에만 나타납니다. 불구름은 주먹의 3배 피해, 재사용 대기 2.2초입니다.
- 첨부 OGG 음악을 반복 재생하며, 호환용 MP3도 포함했습니다. 시작 버튼을 누르면 음악이 재생됩니다. 둔탁한 타격 효과음은 유지했습니다.

## 굿즈와 캐릭터

- 일반 적은 1 C씩, 모몽가는 10 C: **한 번 클리어하면 총 40 C**.
- 팝콘통 / 피규어 / 훌라 키링은 **각 40 C**, 한 회차에 하나만 구매합니다.
- 세 번 클리어하며 서로 다른 굿즈를 구매하면 3종을 모두 모을 수 있습니다.
- 3종 수집 시 **맥도날드 우사기**가 해금되고, 다음 게임부터 자동 선택됩니다. 시작 화면에서 기본 우사기와 바꿀 수 있습니다. 외형이 달라지며 능력치는 같습니다.
- 코인은 다음 회차 시작 시 0으로 초기화합니다. 재도전 시에는 해당 구역 시작 시점의 코인으로 돌아가므로 중복 획득되지 않습니다.
- 굿즈·해금·선택 캐릭터·누적 클리어·최고 기록은 브라우저의 localStorage에 저장됩니다. 기기·브라우저·사이트 주소가 다르면 별도 기록이며, 브라우저 데이터 삭제나 시크릿 모드 종료 시 사라질 수 있습니다.

## 파일과 실행

- index.html: 배포용 게임 전체. 외부 라이브러리나 CDN, API 키 없이 실행됩니다.
- README.md: 설명 및 배포 방법.
- .nojekyll: GitHub Pages 정적 배포 보조 파일.

코드를 수정하려면 index.html 하단의 스크립트와 상단의 style을 편집하세요. 이미지와 음악은 GAME_ASSETS의 data URL로 포함되어 있습니다.

## 검증

키보드에 해당하는 이동·점프·공격 입력으로 3구역 클리어, 정확한 코인 예산, 3회차 구매와 해금, 저장 후 재실행, 모바일 캔버스, 보스 소환 및 음악의 반복·일시정지·음소거를 자동 검증했습니다. 실제 브라우저와 모바일 기기에서의 화면·오디오 재생 확인은 별도로 필요합니다.
